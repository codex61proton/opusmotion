# The Moon Files

A vertical (1080×1920, 30 fps) documentary short about two declassified CIA operations: **Moon Bounce ELINT** (1964–65) and **the Kidnaping of the Lunik** (1959). Everything in it is generated by code: vector motion graphics, a GLSL globe and Moon, procedural sound design, and neural narration. There is no music.

- `film/script.py`: narration and caption markup. Every line is sourced in `docs/sources.md`.
- `film/part1.py`, `film/part2.py`: shots. `film/main.py`: assembly. `film/sound.py`: sound design and mix.
- `engine/`: renderer (Skia + ModernGL post), typography and captions, globe/Moon shader, procedural SFX.
- `docs/sources.md`: claim-by-claim fact check. `docs/image_prompts.md`: prompts for optional photoreal plates.

Rebuild (requires the `/opt/spy` toolchain):

```bash
SPEED=1.15 python tools/tts.py                 # narration + word timings -> build/vo
python film/sound.py                           # -> build/audio/mix.wav
python -c "from engine.render import render_video; render_video('film.main','build/render/video.mp4',workers=2,crf=14)"
tools/mux.sh build/render/video.mp4 build/audio/mix.wav build/the_moon_files.mp4
```
